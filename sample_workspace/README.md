# Sample Workspace for ForgeLocal

This directory serves as a sample project you can select as your active workspace in ForgeLocal.

## Files
- `calculator.py`: Arithmetic functions (add, subtract, multiply, divide, average)
- `test_calculator.py`: Pytest test suite

## Suggested experiments with ForgeLocal
1. Open `calculator.py` in the ForgeLocal editor.
2. Ask ForgeLocal: *"Add a function to calculate factorial, write unit tests for it, and run pytest."*
3. Review the proposed diff in the **Approval Screen**.
4. Click **Approve & Apply** to update the file.
5. In the ForgeLocal Terminal panel, execute `pytest -v` to verify your new feature!
